## Overview

Backyard AI is a desktop application for running local AI language models tailored for character-based companion and roleplay conversations. It provides a curated library of character cards, runs models fully offline using optimized quantized versions, and features a clean chat interface with memory, persona, and world definition configuration.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Backyard AI** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Character Library** | Curated library of pre-configured AI character cards for download |
| **Fully Offline** | All inference runs locally — no data sent to external servers |
| **Memory System** | Configurable long-term memory for persistent character relationships |
| **World Definitions** | Set scene, location, and context through world card definitions |
